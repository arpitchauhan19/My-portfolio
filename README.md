# Arpit Chauhan — Portfolio

Personal portfolio for placements and professional profiles.

## Preview locally

```bash
npx serve .
```

Then open the printed local URL.

## Deploy (GitHub Pages)

1. Push to `main`
2. Repo **Settings → Pages → Deploy from branch → `main` / `/ (root)`**
3. Site will be at `https://arpitchauhan19.github.io/My-portfolio/`

## Stack

Static HTML, CSS, and JavaScript. No build step.
